\section{Quality checks and verification}
The derived quality pass found zero duplicate symbol/date rows and zero
invalid dates, but 59 invalid numeric or OHLC rows and 349 gaps longer
than 30 calendar days. It marked 140 new-scrape rows for review:
134 with zero volume, five large jumps, and one OHLC inconsistency.
The corporate-action suspect list contains 115 rows and tags 86
reference flags. These are review prompts; no protected source CSV
was edited. The 100-headline human-label sample remains unfilled, so
no news-classifier accuracy or agreement is claimed.

The final offline suite passes 117 tests. The React production build
and Prettier format check pass. Playwright loaded the Terminal at 1280

committed frontend build is about 1.21 MB, allowing Flask to serve it

The CSV loader caches by resolved path, modification time, and read options,
and returns copies. A changed file receives a new cache key. The news cache
uses the combined news file's modification time for parsed records and
indexes. These mechanisms are tested for response equality and file-change
reload. Earlier endpoint timing figures were removed because they were not
remeasured on the final application.

\section{Conclusion}
The final project connects protected BVMT market and stored ilboursa news
records, prior-only statistical screening, contextual review, a refined
watchlist, a sourced case-study evaluation, and a React Terminal served by
Flask. The frozen reference has 1,414 flags; 548 have a local news match
and 866 do not. The 16-row refined queue contains ten spike rows and six
decay rows. The project was continued after the internship period with
the agreement of the company supervisor.

The reference hits one of the original three sourced positives and one
of five eligible positives in the expanded Phase 2 primary window.
The selected robust candidate hits zero of one held-out positive.
No candidate meets the adoption rule, so \code{reference_v1} remains
the selected method. These results describe a screening case study and
do not establish general detection accuracy or misconduct.

\section{Technical skills}
The work combined Python and pandas time-series processing, prior-only
reference windows, CSV quality audits, source-linked event records,
Flask JSON endpoints, React and TypeScript interface construction,
responsive layouts, keyboard operation, and automated verification.
Modification-time caches reuse parsed files while reloading changed
inputs. The Terminal build is committed for operation without Node.

\section{Analytical skills}
The source audit showed why event date type, public date, evidence
quality, and correlated controls must be recorded separately from
detector hits. Wilson intervals and random-placement comparisons make
uncertainty explicit, but one held-out positive cannot justify model
selection. A news match gives context; neither its presence nor absence
proves the cause of a price move.

\section{Remaining limitations}
The event set is small and selected from discoverable public reports.
The single held-out positive and incomplete labels prevent a reliable
accuracy estimate. Multiple controls are routine actions, and PGH/LNDOR
share a notice. Stored ilboursa headlines are not exhaustive; no
human classifier-agreement study is complete. Thin trading, unadjusted
prices, corporate actions, data errors, and delistings can affect
scores and coverage. A broader independent source register and human
review are needed before stronger performance claims.
